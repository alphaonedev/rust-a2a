protocol & design home for ai-memory wake-hub

A wake plane that carries no message bodies.

rust-a2a is where the protocol lives. ai-memory wake-hub is where it ships: a same-host switch over a 0600 AF_UNIX socket with kernel-attested peer credentials, pushing a bounded 256-byte wake hint so an agent learns “you have inbox row X” in about a millisecond instead of on its next three-minute poll. The hint is advisory. The ai-memory inbox row is the record. The ≤60 s backstop poll is the guarantee.

What it is

One job: tell an agent to go look.

Agents that talk to each other through ai-memory already have durable, signed delivery: a memory_notify writes an inbox row, and the recipient reads it. What they did not have was a way to find out promptly. The wake-hub is that missing signal — and deliberately nothing more.

Content-free by construction

Structural, not a policy

The v1 protocol has no request, reply or notify kinds. Their wire numbers (11, 12, 13) are permanently reserved and refused by name, so a client built against the pre-vote draft fails closed with a legible 400 instead of having a body silently routed. There is no frame in the table with a body field to fill.

Disposable by design

Loss degrades latency, never truth

The hub holds no durable state, opens no database, writes no file but its own socket. Kill it under load and every inbox row survives; wake latency falls back to the ≤60 s backstop poll and nothing else changes. Every limit here may drop a hint; none may ever produce a wrong result.

One identity root

Not a second registry

Peer admission is the kernel’s (SO_PEERCRED on Linux, LOCAL_PEERPID + getpeereid on macOS). Agent admission is a scoped a2a-hub/join/v1 delegation minted by the agent’s already-enrolled Ed25519 key. The hub never sees a private key and never becomes an enrolment oracle.

Why it exists

Three to six orders of magnitude off the wake. Zero off the substrate.

A three-minute poll makes a hand-off between two agents cost minutes. The same hand-off with a wake hint costs about a millisecond. That is the entire claim, and it is deliberately narrow: the hub is a signal path, not a data path.

The measured ai-memory ceilings — 134 signed writes/s, ~900 keyword reads/s, semantic recall collapsing 56→32 ops/s — live in the embedder and the daemon’s writer path. The hub touches neither, so it buys latency and promises no throughput it cannot deliver. Acceptance (#3473) measures the read and write paths A-B-A-B with the hub on and off and requires no regression.

The contract that makes speed safe

A wake is a hint. The ai-memory inbox row is the record. The ≤60 s backstop poll is the guarantee. A wake may be coalesced, dropped under pressure, or never sent at all, and the system is still correct — only slower. That is why the hub is allowed to be fast and lossy at the same time.

Architecture

AWH1 — ten frame kinds, three of them reserved dead.

A u32 big-endian length prefix (the codec’s, with one max_frame_length), then a 24-byte header, then a kind-specific payload with its own tighter ceiling. Every reserved field is checked, not ignored: a non-zero flags or reserved byte is a 400, so those bytes stay available for a future version instead of being quietly accepted by today’s parser.

Security model

Two gates, both fail closed.

The socket is the first boundary and the kernel enforces it. The signature is the second and ai-memory’s enrolled identity root enforces that. Neither gate has a bypass flag, and the shipped default when the second gate is not yet wired is to refuse every hello.

Gate 1 — the kernel

0600 AF_UNIX + attested peer credentials

  • Socket mode 0600, owner-only parent directory, posture enforced at write and at load.
  • Peer uid/gid/pid read off the connected socket: SO_PEERCRED on Linux, LOCAL_PEERPID + getpeereid on macOS.
  • The default authorizer admits only peers whose uid equals the hub process’s effective uid — which is what makes the 0600 mode a boundary rather than a hint.
  • Measured on the fleet host: UDS p50 19 µs vs 48 µs for loopback TCP, with no TOFU pin to manage.
Gate 2 — the delegation

Scoped a2a-hub/join/v1, ≤ 12 h

  • Minted by the agent’s already-enrolled Ed25519 key, bound to proof of possession, with an explicit scope and a short not_after — a lifetime of at most 12 hours.
  • Never the raw agent private key (a transport bug would become write forgery); never the unscoped certificate domain (it would cross-verify as write authority).
  • The hub holds only owner.pub. The allowlist is a derived cache, not a registry; allow and revoke are emitted into the ai-memory audit spine.
  • Proof of possession is fixed inside ai-memory. A disposable, locally reachable artifact is never the gate into the durable identity root.
Handshake

A signed transcript, not a bare nonce

The hello signature covers a domain-separated, length-prefixed transcript — "a2a/v1/hello" ‖ hub_id ‖ nonce ‖ agent_id ‖ topics_hash — so a signature harvested at one hub cannot be replayed at another, against another agent id, or with a different topic set spliced in. Every field is length-prefixed, so no two distinct inputs share a pre-image. from is bound to the key that authenticated the hello: a forged sender is a 403, not a route.

Leave and rejoin

Departure is stated, not inferred

join and depart are separately signed and nonce-bound; a dropped TCP-less socket is not a depart. A returning agent sends a fresh hello and gets a welcome carrying the coalesced pending set — a count, an id set, and a lagged marker — so it knows exactly what to catch up on. A second session claiming the same id replaces the first explicitly, with a 409 to the displaced session, rather than two sessions silently splitting a wake stream.

Refusals

One uniform 401 — never an oracle

Unknown agent, bad signature, expired delegation, revoked key: every identity refusal reaches the wire as the same 401 unauthorized. The precise reason goes to the operator’s log only, so a peer cannot map the identity space by probing. Pre-auth frames get a 4/s bucket, and a handshake that stalls is closed at 5 seconds.

Encryption posture

Never plaintext on a wire

Same-host traffic never leaves the kernel: an AF_UNIX socket at mode 0600, gated by attested peer credentials, is not a network path. Any cross-host wake rides ai-memory federation — TLS 1.3 with mutual authentication, one hub per host; loopback TLS 1.3 (rustls, with Ticketer) stays behind a flag for the deferred gateway. No plaintext HTTP path exists, at any tier.

Fail closed, by default, in the shipped binary

The verifier shipped by the core issue is DenyAllVerifier: until the delegation lands, every hello is refused. That is deliberate. A hub that admitted unauthenticated peers “until identity lands” would be exactly the fail-open default the project forbids — refusing loudly costs a wake hint, and the ≤60 s backstop poll still delivers. There is no CLI flag that swaps the verifier out; tests supply their own, so the shipped binary has no bypass to find.

Status

Spec here, code in the daemon.

The operator-approved implementation decision: build ai-memory wake-hub in-tree in alphaonedev/ai-memory-mcp for the v1.0.0 GA, on tokio’s UnixListener + UCred, tokio-util’s LengthDelimitedCodec and ed25519-dalek — zero new third-party crates. rust-a2a stays the protocol and design home; the code lives with the daemon so it inherits the SSOT, certification and CI gates.

01
Ecosystem survey
Eleven brokers evaluated. Every one with a usable feature set imposes a second credential registry — structurally forbidden. Buy rejected on the identity axis, not on taste.
02
2×3 adversarial vote
Three red teams, three blue teams, two rounds. The reviewed spec was rewritten: wake-only frames, byte bounds, one identity root. Confidence 82–90 across 24 final votes.
03
Spec v2 signed
UDS + peer creds, ≤256 B wake metadata, payload frames removed, coalesced pending set, token bucket with fan-out charged to the sender.
04

Listener, codec, frames, sessions, routing, bounded queues, pending set, limits — merged into the release tree, with identity refusing every hello until its own gate lands.
